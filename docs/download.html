Heads-up: one clean install for LuniOS 1.3.0. Starting with 1.3.0, LuniOS is signed with its own private keys instead of the public test keys. Phones on 1.2.x or older cannot update to 1.3.0 or newer over the air: install 1.3.0 once with a factory reset (steps below). After that, updates arrive over the air again as usual.

Install

First installation

You need a computer with adb and fastboot. The first install erases the phone; later updates do not.

  1. Unlock the bootloader

    Turn on OEM unlocking in Developer options, reboot to the bootloader and run fastboot flashing unlock.

  2. Flash LuniOS Recovery

    From the release page, download boot, dtbo, vendor_kernel_boot and vendor_boot, and flash each one with fastboot flash <name> <name>.img.

  3. Install the system

    Boot into recovery, choose Factory reset, then Apply update and Apply from ADB, and run adb sideload LuniOS-….zip.

  4. Restart

    Go through setup. New versions will show up in Settings, LuniOS Updates.

Back up your data first. Do not relock the bootloader while LuniOS is installed. LuniOS is an early beta: install it at your own risk.
