# LuniOS

LuniOS is a custom Android 17 ROM based on LineageOS, with a liquid glass design, Google apps
and over-the-air updates. The first supported device is the Google Pixel 8a (akita).

LuniOS is in an early stage. Its source code is closed for now and is planned to be
released under an open source license once the project is ready. LuniOS is built openly
with the help of AI.
